# Coup II – Dokumentation

## Dokumentenhierarchie

Bei widersprüchlichen Informationen gilt folgende Priorität:

1. PROJECT_VISION → Ziel und Designphilosophie
2. ENGINE_SPEC → Technische Architektur
3. ADR (Architecture Decision Records) → Verbindliche Architekturentscheidungen
4. MISSION_DESIGN → Missionsstruktur
5. GAME_DESIGN → Spielmechanik
6. ROADMAP → Geplante Entwicklung
7. CHANGELOG → Bereits umgesetzte Änderungen

---

## Entwicklungsprozess

Neue Funktionen werden grundsätzlich in dieser Reihenfolge entwickelt:

1. Idee
2. Spezifikation (ENGINE_SPEC)
3. Architekturentscheidung (ADR)
4. Review
5. Implementierung
6. Test
7. Release
8. Dokumentation im CHANGELOG

---

## Dokumente

### PROJECT_VISION
Langfristige Zielsetzung und Designphilosophie.

### ENGINE_SPEC
Verbindliche technische Spezifikation der Simulations-Engine.

### ADR
Dokumentation grundlegender Architekturentscheidungen.

### MISSION_DESIGN
Aufbau und Struktur einzelner Missionen.

### GAME_DESIGN
Spielmechaniken außerhalb der Engine (Kampagne, Wirtschaftssystem usw.).

### ROADMAP
Geplante Entwicklungsschritte.

### CHANGELOG
Chronologische Liste aller umgesetzten Änderungen.
