# ENGINE_SPEC.md

## Simulations-Engine 1.0

### Leitprinzipien

-   Alles ist ein Objekt.
-   Jedes Objekt besitzt Zustände.
-   Aktionen verändern Zustände.
-   Zustandsänderungen erzeugen Ereignisse.
-   Die Engine kennt alle Objekte.
-   Der Spieler kennt nur bekannte Informationen.
-   Der Spieler plant Aktionen, nicht spontane Reaktionen.

### Kernbereiche

-   Personen
-   Objekte
-   Aktionen
-   Ereignisse
-   Zeitmodell
-   Wissensmodell
-   Validator
