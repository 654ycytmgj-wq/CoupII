## GitHub

1. Das Änderungs-ZIP entpacken.
2. Im Repository `Add file` → `Upload files` wählen.
3. Den Inhalt des Ordners `der-grosse-coup` hochladen.
4. Vorhandene Dateien ersetzen.
5. Commit-Text verwenden:

   `0.3.0-alpha.2: Aktionsbearbeitung, Türen und Engstellenprüfung`

6. Unter `Actions` auf den grünen Haken für `pages build and deployment` warten.
7. Die GitHub-Pages-Seite in Safari neu laden. Bei installierter PWA die App vollständig schließen und erneut öffnen.

## iPad-Test

1. Versionsanzeige `0.3.0-alpha.2` prüfen.
2. `Plan prüfen`: Der Referenzplan muss ohne Meldung bestehen.
3. Bei Bruno eine Wartezeit ändern.
4. Eine Aktion nach oben und wieder nach unten verschieben; anschließend den Referenzplan erneut laden.
5. Simulation starten.
6. Prüfen, dass Haupt- und Hintertür im Protokoll geöffnet werden.
7. Beim Kassenereignis gibt es keinen Button `OK – pausiert bleiben` mehr.
8. `OK und fortsetzen` wählen und den vollständigen Abschluss abwarten.
