# DESIGN_DECISIONS.md

DD-001: Alles ist ein Objekt.

DD-002: Aktionen sind Zustandsübergänge.

DD-003: Die Engine kennt alle Objekte, der Spieler nur bekannte
Informationen.

DD-004: Missionen lernen mit; entdeckte optionale Objekte bleiben für
spätere Einsätze bekannt.

DD-005: Der Spieler plant Aktionen; operative Selbstverständlichkeiten
übernimmt die Engine.
